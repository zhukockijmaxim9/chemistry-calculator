# Работа № 2. Выбросы химических веществ

Учебный калькулятор на Python и обычном HTML, CSS и JavaScript. Он численно решает систему из 11 уравнений, строит графики показателей и внешних факторов и выводит лепестковые диаграммы для четырёх четвертей расчёта.

## Запуск

Откройте PowerShell в папке проекта. Если окружение `.venv` уже настроено, запустите сервер одной командой.

```powershell
.\.venv\Scripts\python.exe -B app.py
```

Откройте [страницу калькулятора](http://127.0.0.1:8000). Для остановки сервера нажмите `Ctrl+C`.

На новом компьютере сначала создайте локальное окружение и установите в него зависимости.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если Python установлен через uv, используйте `uv venv .venv` и `uv pip install --python .\.venv\Scripts\python.exe -r requirements.txt`.

## Как устроен сценарий

- **Начальные условия** задают 11 значений `X` на момент `t = 0`.
- **Внешние факторы** задают начальные и конечные значения 7 факторов `F`. Между двумя точками программа использует линейную зависимость. Если значения одинаковые, фактор постоянный.
- **Зависимости модели** показывают форму каждого слагаемого и позволяют менять его коэффициент. При нулевом коэффициенте вклад отключается.
- **Результат** содержит 101 расчётную точку на интервале от 0 до 1. Лепестковые диаграммы и таблица показывают значения в моменты 0,25, 0,5, 0,75 и 1.

Наведите курсор на линейный график или коснитесь его, чтобы увидеть значения всех видимых линий в выбранный момент. На лепестковой диаграмме подсказка показывает значение выбранной оси. С клавиатуры перейдите на график клавишей `Tab` и выбирайте точку стрелками. `Escape` закрывает подсказку.

## Допущения модели

В задании схема и таблица 1 описывают 11 показателей, а иллюстрация системы (4) содержит 13. В рабочем варианте применены 11 показателей и формы зависимостей из таблицы 1. Например, для `X9` используется слагаемое `f9⁺`, которое есть в таблице, а для `X8` используются оба табличных слагаемых.

Коэффициенты и начальные значения подобраны для учебной демонстрации. Все состояния и внешние факторы выражены условными индексами от 0 до 1. Положительные вклады умножаются на `1 − X`, отрицательные — на `X`, чтобы индексы оставались на этой шкале. Делители защищены нижней границей 0,1. Формы зависимостей и расчёт сосредоточены в `model.py`, чтобы можно было заменить редакцию модели после уточнения задания.

## Вычислительный эксперимент

Выберите по очереди «Раннее оповещение» и «Позднее оповещение». Между сценариями меняется только `F5` — условный индекс задержки оповещения.

| Показатель | Раннее оповещение | Позднее оповещение |
|---|---:|---:|
| `F5` в сценарии | 0,20 | 0,70 |
| `X3`, площадь заражения при `t = 1` | 0,3855 | 0,3855 |
| `X6`, пострадавшие от вторичного облака при `t = 1` | 0,0946 | 0,1929 |
| `X7`, госпитализированные при `t = 1` | 0,1325 | 0,1440 |

В расчёте с поздним оповещением выросли индексы `X6` и `X7`, а `X3` остался одинаковым с указанной точностью. Значения относятся к двум учебным сценариям.

Индекс эффективности оповещения `X11` в этой версии также растёт при переходе к позднему сценарию. Это особенность выбранной зависимости с обратной величиной `F5`, которую нужно сверить при уточнении модели.
